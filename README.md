### 👩‍💻 About Me

I am a **Software Engineer** specializing in **backend systems, full-stack web applications, and applied machine learning/AI**. My focus is on building resilient, high-integrity software where architectural details matter, from schema design and deterministic scoring algorithms to idempotent payment workflows and automated MLOps pipelines.

- 🎓 **Education:** Graduated **3rd in Batch** with a **3.81 CGPA** in **B.E. Software Engineering** from *Mehran University of Engineering and Technology (MUET)*.
- 💼 **Industry Experience:**
  - **Effective Risk Management** *(Remote · Australia)*: Building enterprise risk intelligence products, deterministic scoring engines with bounded LLM classification, resumable SEC EDGAR data pipelines, and full-stack marketplaces.
  - **10Pearls** *(Remote · Pakistan)*: Developed end-to-end 72-hour air quality forecasting pipelines with MLOps automation and model explainability.
  - **Buildables** *(Remote · Pakistan)*: Engineered RAG-grounded prompt optimization platforms and voice-to-voice AI assistants.
  - **TIERS Limited & BitsPro**: Built full-stack web platforms and REST APIs using Django, Go, and React.
- 🔭 **Current Goal:** Open to high-impact **Backend** or **Full-Stack Software Engineering** roles.
